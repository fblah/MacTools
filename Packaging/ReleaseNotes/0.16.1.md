### Fixed

**File Shelf** — a file dragged out of the shelf now keeps its name. The drag
handed over the file's contents ahead of its location without saying what the
file was called, so an app receiving it had to invent a name.

A row whose file has gone missing since the last check no longer starts a drag
that delivers nothing.
